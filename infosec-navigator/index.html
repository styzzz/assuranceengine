Information security module

Find the control, the evidence that proves it, and the requirement it meets.

The InfoSec Navigator is a catalogue of information security control objectives. For each one it lists the read-only evidence an assessor needs, the test steps, the pass criteria, and the conditions under which the assessor must abstain instead of concluding.

Architecture

How the Navigator fits together

Seven operating components sit on a knowledge layer and a platform layer. Select a component to filter the controls above. The knowledge and platform layers are design intent and are not built.

Specified, not built

NAVIGATOR AI companions

Each companion answers one executive or engineering question from the control records. None of them exists in this repository yet. Each one lists what it needs before it can answer. Where that evidence is missing, the answer must be insufficient evidence, not a guess.

What the catalogue covers, and what it does not yet

Every framework reference the catalogue uses is counted. References with no control yet are listed as gaps so they are not mistaken for coverage.

Reading a result

The six assessment states

Each control assessment in the AssuranceEngine ends in one of these states. The Navigator defines the question and the evidence. It does not make the conclusion.

No evidence means no finding. If an abstain condition on a card applies, the assessor records insufficient_evidence with that reason. A person approves every conclusion before it counts.
